## Purpose

帮助管理员从真实账本、持久审计和结构化日志了解用户消耗与故障原因，在跨用户管理查询中保留权限边界、读取留痕以及未知或过期数据的明确语义。

## ADDED Requirements

### Requirement: 账本查询
系统 SHALL 读取 Redis 日/月账本及金额预算，展示 pending/unknown、统计周期与剩余额度精确性，不以审计数据计费。
#### Scenario: 数据不可用
- **WHEN** Redis 不可用或查询历史已过保留期
- **THEN** 展示故障或过期状态，不展示为零用量

### Requirement: 日志和管理员审计
系统 SHALL 提供分页筛选的持久运行日志和跨用户内容审计查询，并记录管理员操作与内容读取；普通用户权限不扩大。
#### Scenario: 关联尝试
- **WHEN** 管理员查看发生额度切换的请求
- **THEN** 可看到前后模型、Key 引用、独立尝试和可用内容，不含密钥值
#### Scenario: 不完整内容
- **WHEN** 请求断流、截断或内容到期
- **THEN** 展示对应状态；工具指令和 Agent 执行上报可区分
#### Scenario: 依赖故障与权限
- **WHEN** Audit Store 不可用或普通 Key 调用管理员接口
- **THEN** 分别返回明确依赖错误或认证错误，而非空列表
